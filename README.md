> **כניסה למערכת:** [https://roeeiluz.github.io/RAMBAM_OBGYN_PD/](https://roeeiluz.github.io/RAMBAM_OBGYN_PD/)

מערכת web לניהול הערכות מתמחים מבוססת מתודולוגיית CBME (Competency-Based Medical Education) ו-6 הקומפטנציות של ACGME 2.0.

---

## 📋 מה זה CBME?

CBME = Competency-Based Medical Education — חינוך רפואי מבוסס יכולות. במקום למדוד התקדמות לפי שנים בלבד, מודדים יכולות מדידות בפועל בקליניקה. המערכת תומכת ב:

- **הערכות מיידיות (Micro)** — נקודתיות, לאחר כל אירוע משמעותי (ניתוח, לידה, משמרת)
- **הערכות תקופתיות (Macro)** — סיכומים רבעוניים מצרפיים מבכירים + הערכה עצמית של המתמחה
- **EPAs** — סולם 1-5 של רמת אמון שניתן למתמחה לפעולה עצמאית

לחומר הפדגוגי המלא: ראו את לשונית "מתודולוגיה" במערכת לאחר ההתחברות.

## 🛠️ ארכיטקטורה

- **Frontend:** קובץ HTML יחיד (`index.html`) — Vanilla JS + Tailwind CDN
- **Backend:** Google Apps Script (`Code.gs`)
- **אחסון:** Google Drive (תיקיית `CBME_OBGYN/`)
- **אימות:** Magic Link (קוד 6 ספרות במייל, session 24 שעות)

### תיקיות Drive
```
CBME_OBGYN/
├── procedures/        — קבצי Excel של פעולות מצטברות
├── exams/             — תוצאות מבחני שלב
├── evaluations/
│   ├── micro/YYYY-MM/ — הערכות מיידיות לפי חודש
│   └── macro/QUARTER/ — סיכומים רבעוניים (drafts/finals)
├── sessions/          — Magic Link tokens
├── staff/             — משתמשים דינמיים
├── user_settings/     — העדפות אישיות לפי משתמש
└── audit-log.json     — לוג פעולות מערכת
```
