## 🎯 מטרת המערכת

מערכת חכמה רב-שכבתית שמחליפה טפסי הערכה מסורתיים ב-3 רבדים:

| שכבה | מטרה | מי מבצע |
|------|------|---------|
| **Micro-Eval** | פידבק מיידי אחרי פעולה / משמרת | בכיר + צ׳יף + מתמחה (עצמי) |
| **Macro-Eval** | הערכה תקופתית לפי ACGME 2.0 | בכירים + צ׳יפים + מתמחה → אגרגציה למנהלת |
| **Self-Assessment** | רפלקציה אישית | מתמחה |

## 🏛️ הערכה תקופתית (Macro) — Workflow מלא

```
1. הבכירים והצ׳יפים ממלאים הערכה לכל מתמחה
   (ציונים + הערות לכל אחת מ-6 הקומפטנציות)
   ↓
2. המתמחה ממלא הערכה עצמית באותה מבנה
   ↓
3. המערכת אגרגטת אוטומטית את הציונים ומרכזת הערות
   ↓
4. מנהלת התוכנית רואה:
   • ממוצעי ציונים + השוואה להערכה עצמית
   • זיהוי over-confidence ופערים
   • ריכוז כל ההערות מסודר לפי קומפטנציה
   • הצעת סיכום AI ראשונית
   ↓
5. המנהלת עורכת סיכום סופי בגמישות מלאה
   ← מאשרת ← נשלח למתמחה ← נשמר ב-Google Drive
```

## 📋 8 קטגוריות משוב מהיר

| קטגוריה | תת-פעולות עיקריות |
|---------|---------------------|
| 👶 **חדר לידה** | ניהול שלב ראשון, החלטות emergency C/S, תקשורת |
| 🏥 **ניתוח קיסרי** | scrub, כניסה לבטן/רחם, מיילדות עובר, תפירה |
| ✂️ **פעולות בח״נ** | גרידה, היסטרוסקופיה, גישה נרתיקית |
| 🔬 **לפרוסקופיה** | סקופ, מניפולטור, טרוקרים, ציסטקטומי, salpingectomy, TLH |
| 🚨 **מיון** | טריאז׳, כתיבת דיון, חוזק מדיקולגלי, פרוטוקולים |
| 🌙 **תורנות** | מענה למחלקות/נשים, רישום, עומס, צוות, חירום |
| 📋 **אחריות מחלקה** | מקרי דגל, ביקורים (SOAP), מכתבי שחרור |
| 🩺 **מרפאה** | אנמנזה, אבחנה מבדלת, תקשורת, תיעוד |
